# Getting started with Metria

Install the published package and prepare a local CPU comparison using the
[llama.cpp verification guide](metria-verify.md). It covers the pinned runtime,
model, recipe, output files, and interpretation of the result.

For other entry points, see the [documentation index](../index.md).
